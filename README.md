Сценарий:
1. Приглашение в кино.
2. Выбор еды: суши / итальянская / бургеры / десерты.
3. Выбор поездки.
4. План свидания.
5. Новый экран: «И последний вопрос... Насколько сильно ты ждёшь нашу встречу?» со слайдером 0–100%.
6. Финальный романтичный экран.

Ответы сохраняются в Supabase в `date_answers`.
