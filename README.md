Настройка сохранения ответов:
1. Создай проект в Supabase.
2. SQL Editor → вставь supabase.sql → Run.
3. Возьми Project URL и Publishable key и вставь в config.js.
4. Залей обновлённые файлы в GitHub и сделай новый Deploy в Vercel.
5. Ответы смотри в Supabase → Table Editor → date_answers.
НЕ вставляй Secret/service_role key в config.js.
